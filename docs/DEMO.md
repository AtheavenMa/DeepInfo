# Offline DeepInfo demo

## Installation and one-command run

```bash
python -m pip install -e ".[demo]"
python demo.py
```

Everything the demo needs is included in `assets/examples/colored_disk.npz`, `assets/checkpoints/tiny_cnn.pt`, and `model.py`. No dataset service or model hub request is made during inference.

The 32×32 RGB sample was generated by `scripts/make_assets.py`: a colored disk against a procedurally generated textured background. A tiny CNN was trained on generated red/green disk images to classify disk color. This small training experiment is only a readable illustration of CID; it is **not a pretrained network or an empirical reproduction** of the ICML 2022 reported benchmarks.

## What the demo computes

The script estimates CID at `stem.1` (shallow ReLU), `block.2` (intermediate ReLU), and the model output (selected class logit). It uses the same input, noise-grid resolution, random seed, and optimization hyperparameters for all three layers. More noise entropy means greater tolerance to input variation. All values are in nats per input coordinate, and coarse noise cells are upsampled for visualization.

```
python demo.py --device cpu
python demo.py --steps 48 --noise-samples 12
python demo.py --grid 4 --output outputs/lowres
```

| Output file | Contents |
|---|---|
| `demo_output.png` | The synthetic input and three actually computed input-space CID maps |
| `layerwise.png` | Layer means, using the same measurement units |
| `attribution.npz` | Original input, foreground mask, per-layer CID maps |
| `summary.json` | Configuration, model/sample SHA256, selected steps, distortion ratios, numerical results, and versions |

Inspect the bundled [demo summary](../assets/summary.json) and [sample metadata](../assets/examples/metadata.json), or rerun the demo with your own seed and output directory. Save large runs outside `assets/`.

## Recreate the bundled assets

```bash
python scripts/make_assets.py
python demo.py --output assets
```

Regenerating the model weights with a different PyTorch version or CPU/GPU implementation can result in slightly different numeric weights even when using the same seed. Recompute `summary.json` after doing so. The repository includes a deterministic test and smoke-test workflow.

## Using a real model

Supply your own network and already preprocessed image to `deepinfo.explain`. Set a named intermediate layer, use `selector` to fix the output of interest, and start with a modest noise grid, e.g. `grid=(8,8)`. For deeper layers on large images, increase `noise_samples` and `steps` after verifying the initial distortion is meaningful. The feature scale and preprocessing must remain fixed when comparing layers.

To examine RU on convolutional layers, train a compatible decoder on separate representative images, then pass it to `explain_ru`. Refer to [METHOD.md](METHOD.md) for the estimator and limitations.
